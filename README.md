## Part I 机场选购指南

说到科学上网，目前主流的方式有四个：VPN，国外流量卡，机场，自建。

VPN 的安全性太差，封装好的模子你完全不知道他会在你的设备上面干什么，所以我们不考虑这一项。

国外流量卡价格过高，国内 eSIM 支持也不完整，不考虑。

自建难度很大，非常麻烦，不考虑。

于是，只剩下唯一的选项：

**机场**

机场的使用应该是翻墙里面最方便的了。只需要一个订阅，一个客户端即可。此处我们不详述有了订阅之后，如何导入，如何设置的问题。我们只来说说哪些机场比较好，当然仅作为一些推荐。

本教程不会推荐任何我没有用过的机场，不会有任何的广告成分（但是会有我个人的 aff，当然可以自行删除）

目前，这一系列仍然是性价比最高的一个系列，包括奶昔，库洛米，imm，amy，花云，绿叶，西数等一系列中高端机场。目前，我仅推荐三家机场：

花云，西数，绿叶。

理由：奶昔，kuromis，imm，amy 价格过高，虽然节点质量比较好，但是我认为性价比不及上面提到的三个。

#### 花云

花系以花为名，就是因为花云----flowercloud。基本上用的是差不多的线路，所以一个炸全部都炸。但是好在它们几乎不会炸，相比于其他机场。

花云最让我动容的就是它的 0.2 倍率节点。也就是，1G 的流量当成 5G 来用。这样，花云的低价套餐就变成了超大流量。

目前我推荐的套餐是 39 元/月，150G 的流量。花云常年有优惠码，所以基本上加上手续费是 32 元/月。

花云的节点分为三类：实验性节点，高级节点，标准节点。实验性节点全是 0.2 倍率，日常看 emby 甚至足够。其余均为 1 倍率节点。

说实话，三类节点差别实在不大。

实验性节点应该是口子最大的节点，在非高峰期的带宽是最大的，也是最常用的节点。
其余两个问了客服，差别不大，也没必要了解差别。
